
# Palestine Website

Static awareness website organized by page and shared assets.

## Structure

- `index.html` - home page.
- `pages/` - standalone site pages: heroes, truth carousel, auth, donate, about, contact, and gallery.
- `assets/` - shared home assets, scripts, styles, and vendor files.
- `docs/` - downloadable project documents.
- `archive/legacy/` - old experimental or unused files kept for reference.
